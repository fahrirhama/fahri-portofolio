Proyek Saya

Snake Game

Snake Game ini saya buat dengan menggunakan bahasa pemrograman C++ menggunakan pendekatan OOP, dengan tampilan grafis berbasis grid, saya juga disini memakaikan library SFML, bisa terlihat juga dari kode sf::RenderWindow dicode nya jika dicek, Ular akan bergerak di grid, memakan-makanan secara acak, akan semakin bertambah panjang, dan permainan berakhir jika menabrak dinding atau tubuh sendiri.

Web Turnamen Badminton "Shuttle Zone"

Web ini adalah proyek kelompok mahasiswa Universitas Paramadina (5 anggota, 2025, semester 2) yang berupa sistem manajemen turnamen bulu tangkis berbasis web, bernama SHUTTLE ZONE. Tujuannya adalah mendigitalisasi pengelolaan kompetisi yang sebelumnya manual dan terpisah-pisah, sekaligus menjadi media informasi bagi para suporter.

Monster Blocks

Monster Blocks sebuah game arcade sederhana bergaya breakout/tetris hybrid, di mana pemain mengendalikan sebuah paddle atau karakter untuk menghancurkan blok-blok monster yang tersusun di layar; setiap blok memiliki warna dan mungkin jumlah HP berbeda, dan ketika dihancurkan bisa memunculkan efek suara, partikel, atau skor bertambah, sementara pemain harus menghindari bola atau serangan monster yang jatuh agar tidak kehilangan nyawa.
